# FINAL BOSS 共通要件

原典: `FINAL_BOSS_CODEX_CLAUDE_PROTOCOL.md`

このフォルダの企画・実装・レビューは原典を最上位の判断基準とする。特に以下は変更しない。

1. 既存4ボスをすべて倒した後だけラスボスが出現する。
2. 既存ボスのおよそ10倍の大きさにする。
3. プレイヤーが身体へ実際に乗り、登り、身体上で戦う。
4. 命中部位ごとに損傷・破壊・欠損し、攻撃・移動・姿勢・戦術が変わる。
5. `bosstiu` の実モデルと実アニメーションを調査して利用する。
6. 既存4ボス、通常ステージ、操作、カメラ、UI、セーブ、スマホ対応を壊さない。
7. ダミーで終えず、ビルド・実行・挙動・回帰を検証したプレイ可能状態にする。
8. Blocker / High の未解決事項を残さない。

役割はCodexが「守」、Claudeが「破・離」。Codex初案、Claude批評、Codex統合、Claude最終判定を経た `05_FINAL_CONCEPT.md` のみを実装基準にする。

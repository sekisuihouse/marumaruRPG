# 最終企画 — 祭典終端巨人「ティウ」

この文書が実装フェーズの唯一の企画基準である。`03_CODEX_SYNTHESIS.md` の全決定と `04_CLAUDE_FINAL_REVIEW.md` の必須修正（モバイル仮想ジョイスティック）を統合済み。

## コア体験

既存4ボス撃破後、その報酬と最後の残骸から身長36mの巨人ティウが再構築される。プレイヤーは地上で脚を折り、地面についた腕を登り、動く身体の上で部位を壊し、攻撃パターンと登攀路を自分で変化させる。最後は倒れる実ボーン足場を降りて手のひらへ着地する。

ティウは同時に以下の3つである。

- 敵: 予兆付き攻撃、追尾、反撃、部位に応じた判断を行う。
- ステージ: 6系統の足場が実ボーンへ追従し、登攀・移乗・落下復帰が戦闘になる。
- 結末: 4報酬が巨人を作り、導管破壊後にプレイヤーを守り、最後に町へ帰る。

## 素材

- 本体: `bosstiu/T-Pose.fbx`（46,895頂点、93,790ポリゴン、Mixamo 41ボーン）。
- テクスチャ: `output/boss_textured.glb` / `output/textures/boss_basecolor.png` の既存2K焼き込みを、同一トポロジ検証後にスキン本体へ移植。
- clips: Walking 1.9秒、Swagger Walk 5.567秒、Stomp 3.733秒、Throw Object 9.733秒、Swatting Bugs 13.333秒、Two Handed Sword Death 4.8秒。
- 論理名・トリム・速度・イベント時刻は単一manifestへ集約し、Hipsの水平root motionを除去する。

## 出現と再戦

- 条件は `defeatedBossCount === 4` かつ全4ボスのdefeated確認。
- 初回は4報酬の光と直前ボス残骸が広場へ収束し、巨人が足から組み上がる8秒演出。操作可能、攻撃無効、安全距離を確保。
- 再戦は広場の「祭核の記憶」から開始し、2秒へ短縮。報酬重複なし。
- 戦闘中は半径52mを既存arena機構で封鎖し、通常敵を停止する。

## フェーズ

### P0 祭壇の再構築

低いカメラから、建物と同時に全身を見せる。安全時間後P1へ。

### P1 二本の脚

`world_stomp` と `rubble_throw` を避け、左右すねを攻撃する。片すね破壊で片膝・前腕が接地し登攀路が開く。両すね破壊は後の核戦で地上から最大25%だけ短縮ダメージを可能にする。

### P2 身体は戦場

前腕→肩/背中へ登り、4祭導管を任意順で破壊する。`grip_shake` と最大3個の単純球ハザード `debris_shed` を回避する。導管破壊直後は対応色の `conduit_backlash` が一度だけ発生し、対応する既存ボス報酬が安全帯と長い反撃窓を生成する。導管の時計回り配置は撃破順で回転するが総難度は変えない。

### P3 盲目の巨人

頭・肩ルートで視界冠を破壊する。追尾攻撃が止まる代わりに `blind_charge` を使う。建物へ誘導すると巨人が自傷する。P2/P3の攻略順は一部自由で、導管を残したまま冠へ先行できる。

### P4 祭核

4導管破壊で胸核が露出する。胸足場で内外交互の `core_pulse` を避け、反撃窓に核を攻撃する。両すね破壊済みなら膝つき時に地上から核HPの25%まで削れるが、最後の75%は身体上戦闘が必須。

### P5 最後の降下

核HP0で `Two Handed Sword Death` を0.4倍、約12秒で再生する。通常戦闘と同じ実ボーン追従足場で頭→肩→前腕→手へ降りる。移動・ウェブを使用可能。8秒以降は手のひらを安全姿勢で保持し、落下しても手が救助する。着地後に撃破確定・保存し、4色の光を各地区へ返す。

## 部位

| 部位 | HP | 破壊による変化 |
|---|---:|---|
| 左/右すね | 各420 | 該当踏みつけ停止、旋回/歩行低下、膝つき延長 |
| 左前腕 | 360 | 左払い半幅、恒常登攀路 |
| 右前腕 | 360 | 投擲3→1、恒常登攀路 |
| 4祭導管 | 各180 | 一回逆流後、対応攻撃停止。4本で核露出 |
| 視界冠 | 300 | 追尾停止、盲目突進へ変更 |
| 胸核 | 900 | HP0で死亡降下開始 |

各部位は `intact → wounded(50%) → broken(0%)`。オフラインでボーンウェイト別の外装サブメッシュを生成し、破壊時は外装を隠して断面・傷・最大4破片へ差し替える。本体SkinnedMeshのランタイムBooleanは行わない。

## 攻撃の共通規則

- `world_stomp`: 1.25秒予兆、半径7m、42damage、0.62で発生、後2.8秒反撃。
- `rubble_throw`: 1.6秒予兆、着地点3個、各34damage。右腕破壊で1個。
- `body_swat`: 0.9秒の肩→肘→手発光、30damage。反対足場/グリップへ回避。
- `grip_shake`: 接地足場だけ0.8秒予兆、直接damageなし、移乗/グリップで回避。
- `debris_shed`: 上流1秒発光、最大3球、各22damage、横回避。
- `conduit_backlash`: 導管破壊直後1.2秒予兆、一度だけ36damage、安全帯へ回避。
- `blind_charge`: 2秒直線予兆、48damage、建物へ誘導可能。
- `core_pulse`: 1.1秒内外帯予兆、38damage、反対帯へ移動。

全攻撃に予兆、回避、反撃窓を持たせる。reducedMotionはカメラ誘導を3度/秒へ、mobileは予兆幅を15%広げる。

## 動く足場とウェブ

- 足場系統は `shin`, `thighPalm`, `forearm`, `shoulderBack`, `head`, `chest` の6つ、実体OBB最大9枚。
- ボーンの前/現Matrix差分を接地プレイヤーへ先に適用し、その後ローカル入力を解決する。差分は0.9m/12度/フレームでクランプし、接地切替には2フレームのヒステリシスを使う。
- ジャンプ/ウェブ時は足場線速度を慣性として渡す。
- 巨人アンカーは静的建物registryと分離し、ボーンローカル点に対するray-sphere判定で取得する。
- 落下時は自分でウェブ復帰できる。失敗時は3秒ロスして直前チェックポイントへ自動救済する。

## カメラ

- normal 3.5〜16m（既存挙動を維持）
- finalGround 8〜30m
- finalMounted 5〜18m
- finalCore 4〜13m
- finalDeath 7〜24m

プロファイルは0.6秒補間。静的 `cameraDistance` と、巨人の簡略カプセルに対する動的線分交差の短い方を使い、体内への侵入を防ぐ。

## UI・PC・スマホ

- 全体HP + 部位小ゲージ + 現在目的1行 + 形状アイコン付き部位マーカー。
- スマホは現在目的・対象部位だけ常時表示し、一覧は折りたたむ。
- 既存の `touch.move` を駆動する画面左下の仮想ジョイスティックを共通HUDへ追加する。pointerId捕捉、円形クランプ、pointerup/cancel/visibilitychangeで確実に0へ戻す。通常ステージと既存4ボスでも同じ移動入力として動作する。
- 右側の既存攻撃・ウェブ・回復・盾ボタンを維持し、ジョイスティックと重ならないレスポンシブ配置にする。
- 画面回転・resize後も操作円を再計算する。

## セーブ・死亡・復帰

- 保存: 最終ボス出現/撃破、phase checkpoint、部位状態、導管順、初回演出済み。
- 戦闘中リロードはP1/P2/P3/P4の開始点へ戻し、既破壊部位を復元。
- プレイヤー死亡は同フェーズから再開し、部位進行を維持。連続失敗時は予兆+20%。
- 状態遷移中に高火力でHP0でも、遷移を安全に進めP5へ入る。
- 撃破後は町を自由探索でき、記憶から報酬なし再戦できる。

## 性能予算

- 93,790 polygons、41 bones、2K texture 1枚、12 draw calls以下。
- 足場OBB最大9、部位カプセル最大9、アンカー最大8。
- 破片 high 48 / medium 28 / low-mobile 16、8秒。
- ハザード最大3、particle high 120 / mobile 40。
- dynamic shadowはhighのみ、他はblob。追加light最大1。
- 目標desktop 50〜60fps、mobile low 30fps、連続再戦ヒープ増加5MB未満。

## フォールバック

- モデル/clip失敗: 低ポリゴン人型 + 手続きアニメ。論理timerは継続。
- texture移植失敗: 単色黒 + 4色導管。
- 外装分離失敗: 本体を残し傷・煙・断面リングで欠損表示。
- 足場行列欠損: ボス姿勢を固定しルート基準足場へ切替。
- ウェブ対象欠損: 自動救済。
- 音源欠損: 既存bossChase。
- low/mobile: 影・破片・粉塵を削減し、足場・予兆・部位判定は維持。

# まるごと祭・転生ゲート

`https://2026.marugotosai.jp/` 専用のChrome拡張です。最初に出る3D円盤をクリックすると確認画面を出し、「はい」で白い転生演出の後に最新ビルドのゲームを開始します。

ホームページ上では、マウスカーソルを3Dの町や企画モデルへ合わせて `C` を長押しすると火球を連射できます。火球の当たり判定と破片は、ホームページが描画しているThree.js/R3Fの3D空間で処理します。命中部の三角面が3D破片として飛び、飛んでいる破片に再度当てるとさらに遠くへ飛びます。部品は複数回の命中で外れるため、一発でモデル全体は消えません。元の3Dモデルのサイズ、配置、サイト側アニメーションは変わりません。

## 読み込み方法

リポジトリから取得した場合は、最初にリポジトリのルートで `npm install` と `npm run build:extension` を実行します。これでこのフォルダにゲーム本体とアセットが生成されます。

1. Chromeで `chrome://extensions` を開く。
2. 右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押す。
4. この `marugoto-tensei-extension` フォルダを選ぶ。

ゲーム中は `Esc` で「継続」「まるごと祭ページに戻る」のメニューを開けます。

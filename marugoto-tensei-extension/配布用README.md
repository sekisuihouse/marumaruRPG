# まるごと祭・転生ゲート（非公式Chrome拡張機能）

まるごと祭2026のホームページ上部にある町の3Dモデルをクリックすると、確認画面を経て「未来の町」ゲームを始められる非公式拡張機能です。

## インストール方法（Google Chrome）

1. 配布ZIPを解凍します。
2. Chromeのアドレスバーに `chrome://extensions` と入力して開きます。
3. 画面右上の **デベロッパーモード** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む** を押します。
5. 解凍した `marugoto-tensei-extension` フォルダを選択します。
6. `https://2026.marugotosai.jp/` を開き、最上部の町の3Dモデルをクリックします。

## 使い方

- 町の3Dモデルをクリック → 「転生しますか？」で **はい** を選択 → ゲーム開始
- ホームの町・企画モデルへカーソルを合わせ、`C` を長押し → 火球を連射（局所破壊・破片あり）
- ゲーム中の `Esc` → **継続** または **まるごと祭ページに戻る**
- 初回は画面のチュートリアルに沿って操作してください。

## 注意

- 本拡張機能は非公式です。まるごと祭公式・神山まるごと高専の公式配布物ではありません。
- PC版Google Chromeでの利用を想定しています。
- 配布元の素材・モデルの利用条件は、それぞれのライセンスに従ってください。
